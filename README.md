# 📝 Java Journal App

A robust RESTful API built with **Java** and **Spring Boot** to manage personal journal entries. This project focuses on clean architecture, NoSQL integration, and automated API documentation.

## 🚀 Features
* **Full CRUD Functionality:** Create, Read, Update, and Delete journal entries.
* **RESTful Design:** Standardized API endpoints for seamless integration.
* **NoSQL Persistence:** Integrated with **MongoDB** for flexible data storage.
* **API Documentation:** Fully documented using **Swagger/OpenAPI**.

## 🛠️ Tech Stack
* **Language:** Java
* **Framework:** Spring Boot
* **Database:** MongoDB
* **Documentation:** Swagger UI / OpenAPI 3
* **Build Tool:** Maven
